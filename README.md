# Playlist Maker

Приложение для создания и управления плейлистами музыки.

В папке `checklists/` лежит финальный чек-лист с отметками о самопроверке.

## Технологии и версии

- **Android Studio**: Koala (AGP 8.9.1)
- **Kotlin**: 2.0.21
- **Android SDK**:
  - compileSdk: 36
  - minSdk: 30
  - targetSdk: 35
- **JDK**: 11

## Как собрать и запустить

### Что нужно
- Android Studio Koala или новее
- JDK 11 или новее
- Android SDK

### Сборка

1. Открываю проект в Android Studio
2. Жду, пока Gradle синхронизируется (при первом запуске может занять время)
3. Если что-то не так, пробую File → Sync Project with Gradle Files

### Запуск

1. Подключаю телефон через USB (нужна отладка по USB) или запускаю эмулятор
2. Выбираю устройство в Android Studio (выпадающий список сверху)
3. Нажимаю Run (зелёная кнопка) или Shift+F10
4. Приложение установится и запустится

### Если нет телефона

Можно использовать эмулятор:
1. Tools → Device Manager
2. Create Device
3. Выбираю любое устройство (например, Pixel 5)
4. Выбираю системный образ (API 30 или выше)
5. Создаю и запускаю эмулятор
6. Потом запускаю приложение как обычно

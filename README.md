# Playlist Maker (Android / Jetpack Compose)

Android-приложение для поиска музыкальных треков, управления плейлистами и избранным.  
Проект выполнен с использованием **Jetpack Compose**.

---

## 📋 Требования
Для сборки и запуска проекта необходимо:

- **Android Studio Iguana / Jellyfish и выше**
- **JDK 11**
- **Android SDK 36**
- **Gradle (поставляется с Android Studio)**
- Устройство или эмулятор с **Android 11 (API 30)** и выше

---

## Установка и сборка проекта

### 1. Клонирование репозитория
```
git clone https://github.com/<username>/<repository>.git
cd <repository>
```


### 2. Открытие проекта в Android Studio
- Запустить Android Studio
- Выбрать File → Open
- Указать папку с проектом
- Дождаться окончания синхронизации Gradle


### Запуск на эмуляторе
- Открыть Device Manager
- Создать или выбрать виртуальное устройство (API 30+)
- Нажать Run


### Запуск на реальном устройстве
- Включить Режим разработчика
- Включить Отладку по USB
- Подключить устройство к компьютеру
- Выбрать устройство в списке и нажать Run


### Сборка APK
```
./gradlew assembleDebug
```
